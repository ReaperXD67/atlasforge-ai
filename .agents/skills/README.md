# Project skills

This repository keeps task-specific skills here; global skills and video runtimes are separate.

| Skill | Use |
| --- | --- |
| [Stock music film](stock-music-film/SKILL.md) | Curated footage edits with pinned sources and soundtrack verification. |
| [Cut the Curve](cut-the-curve/SKILL.md) | Match camera direction and velocity across AI-scene cuts; use restrained zoom/rack-focus transitions. |
| [Seam Craft](seam-craft/SKILL.md) | Keep the scene ground opaque and prevent unintended flashes while composing transitions. |
| [Motion Doctrine](motion-doctrine/SKILL.md) | Plan a shared motion direction and concrete carriers across adjacent scenes. |

The three motion-reference skills are pinned to `ThaddeusHackz/THE-AI-VIDEO-EDITOR` revision `d2a6541566554a3323098f8b4a1c1cdf13d0eb44` under Apache-2.0. Each folder includes the original license and `UPSTREAM.md`. They add source guidance and examples, not a new renderer or a paid service. Optional upstream scripts need platform/runtime validation before use; installation alone is not a successful film check.

Use them within the current project and user instructions. Existing HyperFrames deterministic timing, source checks and decoded-frame review remain required. [Research and adoption notes](../../docs/research/bosston-ai-motion-v3-2026-11-18.md)
