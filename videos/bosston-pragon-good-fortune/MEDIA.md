# Media provenance

The active film uses **17 AI-generated environment images**: seven retained worlds and ten new matching scenes. `ai-assets.json` pins their exact local filenames, dimensions, generation origin and SHA-256 values. Every scene in `scene-plan.json` uses this artwork; no stock clip or procedural 3D hero model is mounted in the AI Cinema cut.

- **Soundtrack:** supplied `Boston Pragon 好运来 (1).wav`, 185.000 seconds, 48 kHz stereo PCM16. The original filename remains unchanged. It is the only soundtrack, at zero offset and original gain.
- **Brand:** only the upper-left B emblem and BOSSTON | Pragon lockup from the user's reference were isolated onto transparency using ImageGen. The character, Chinese poster lettering and 2027 banner are excluded.
- **Lyrics:** the user's revised, recording-matched New Year lyrics and corrected **Bosston** spelling are canonical. All 71 cue times and word records are preserved. Raw ASR observations remain separate from display text; timing is model-derived.
- **Artwork:** built-in ImageGen created fictional red/gold festival architecture, luminous dragons and phoenixes, silk landscapes, koi, cloud bridges, lantern rivers, a fortune forge, palace garden, celestial gong and golden lotus. Anonymous tiny silhouettes are synthetic; these are not documentary images of a Bosston event. The ten new images use the original generated worlds as visual references, not the poster character.
- **Depth:** the Apache-2.0 **Depth Anything V2 Small** checkpoint is pinned to revision `5426e4f0f36572d16453bbda7a8389317b1bef99`. Its SHA-256-verified weights run on CPU. `ai-depths.json` records each source/map pair, normalization, inference size and model revision. Maps are relative estimates, 0 far / 1 near, not recovered physical geometry. See [runtime notes and original license](assets/depth/README.md).
- **Animation:** original local WebGL code adds restrained depth displacement, continuous camera travel, selective water/cloth/lantern/cloud motion, atmosphere and optical transitions. This is **animated AI artwork**, not native generated-video footage. It cannot create unseen surfaces or a fully articulated dragon performance.
- **Typography/runtime:** local Noto Serif CJK SC under SIL OFL 1.1 ([notices](assets/fonts/README.md)), local GSAP and pinned HyperFrames 0.8.152. The renderer owns soundtrack playback. Text remains editable HTML and follows the preserved vocal cues.

Three Apache-2.0 editing skills were installed project-locally and reviewed at a pinned upstream commit: [Cut the Curve](../../.agents/skills/cut-the-curve/UPSTREAM.md), [Seam Craft](../../.agents/skills/seam-craft/UPSTREAM.md) and [Motion Doctrine](../../.agents/skills/motion-doctrine/UPSTREAM.md). Their continuous-motion and opaque-compositing ideas were adapted; their POSIX DOM gate is not presented as a validator for the custom shader. [Research decisions](../../docs/research/bosston-ai-motion-v3-2026-11-18.md)

Earlier stock and low-detail 3D studies remain archived and inactive. Their separate [stock credits](STOCK_CREDITS.md) apply only to that experiment. Existing Windows Application Control blocked local Wan and Blender from launching; no security policy was changed. The working CPU depth route uses the installed model architecture directly.

The prepared image/font/audio binaries and model cache stay local; Git contains editable code, manifests, small runtime depth maps, licenses and documentation. Delivery receipts bind the actual local inputs and encoded outputs. The user's current request authorizes pushing this project's tested changes through its existing GitHub workflow.
