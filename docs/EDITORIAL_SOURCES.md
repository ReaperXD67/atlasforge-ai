# Atomy editorial source pack

Brand-focused episodes are generated from dated summaries in `config/default.yaml`. Search trends,
YouTube suggestions, Reddit posts, model memory, distributor anecdotes, and testimonials are never
treated as factual evidence.

The current U.S. pack was checked on 12 August 2026 against:

- [Atomy USA Membership Registration User Guide](https://us.atomy.com/cst/userGuide/24100000001691)
- [Atomy America Member Agreement](https://us.atomy.com/common/footerTermsInfo?isHtml=Y&tabIndex=1)
- [Atomy USA Compensation Plan](https://us.atomy.com/cst/marketingPlan)
- [FTC Business Guidance Concerning Multi-Level Marketing](https://www.ftc.gov/business-guidance/resources/business-guidance-concerning-multi-level-marketing)

The preflight reports the age of the oldest summary. Brand-focused script validation fails after the
configured 90-day limit. To refresh the pack, reread every linked page for the configured region,
rewrite the summaries in original language, update `checked_on`, run the tests, and generate a private
review video. Never copy another region's registration requirements into a U.S. episode.
