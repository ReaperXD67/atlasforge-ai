# BRAG plan: The Yes Machine

Adapted from [`latent-spaces/brag`](https://github.com/latent-spaces/brag/tree/669ab9286aa28b6c3ee30e75f181ee74319d012a), MIT. This is an authored BizNex story and a demonstration of AtlasForge's production workflow, not a literal website launch. The user's vertical format, expressive voice and no-image-model instructions take precedence over BRAG's landscape/Kokoro defaults. Files live in this new project directory to preserve the preceding film.

## Nine-question rubric

1. **What is it?** AtlasForge turns a reviewed story and performance directions into a timed, rendered, verifiable film; this sample teaches deliberate choice through a mechanical metaphor.
2. **Strongest claim?** “One little yes” starts a whole machine. For the repository: “The voice sets the cut. The story sets the motion.” Both describe visible work, not an audience-performance promise.
3. **Visual hook?** A coral YES button so large that the camera must pull back to reveal what it powers.
4. **Actual material?** The canonical script, BizNex identity, speech-word timing and working procedural scene. There is no source product UI to fake.
5. **Shortest satisfying film?** The 54-word performance measures 26.27 seconds, with a 26.3-second frame-aligned timeline. The pause supports the turn; questions retain their complete phrasing.
6. **Tone?** Cinematic with dry, self-aware warmth: a miniature machine takes a tiny decision much too seriously.
7. **Audio?** Intimate original synthetic voice; small physical clicks build pressure, then silence and a warm release. Music supports the performance.
8. **Share caption?** “One little yes can start a whole machine. Three questions can stop it.”
9. **Flow?** Automatic choice → visible consequences → a pause that restores deliberate choice. The companion repository flow is script → checked performance → compiled shots → decoded delivery.

## Audio and reading discipline

The spoken words lead timing. Music beat alignment may adjust minor accents only; it cannot shorten a question or interrupt a complete thought. Short labels need at least 0.8 seconds settled; longer copy needs realistic reading time. Captions remain inside the social title-safe region and do not compete with the physical labels. Foley must have an actual visual cause.

No bundled BRAG music is assumed licensed for this export just because it is available. Use the project's original procedural score/foley and document any selected third-party sounds individually. No automatic claim that technical speech checks measure emotion.
